# dio-spring-ai 

Projeto final do Bootcamp DIO - Java com IA - Itaú

Este projeto permite o envio, via API, de aúdios em MP3 referentes a despesas que serão 
processadas e como resultado será cadastrada uma despesa no banco de dados e depois 
retornado um áudio em MP3 descrevendo a operação realizada.

## Para rodar

1. Configure a chave de API para acesso ao ChatGPT na variável de ambiente OPENAI_API_KEY

2. Execute o comando abaixo:
> ./mvnw spring-boot:run

## Tecnologias utilizadas

- Spring Boot 4
- Spring Data JPA
- Spring Web
- Spring AI / Open AI
- Postgres 18
- Docker Compose
